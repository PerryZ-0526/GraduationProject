## 一、梳理逻辑：五项内容如何归并为三大工作

课题文档列了五项研究内容：①手术场景与可视化需求分析；②动态骨表面表示与更新；③实时计算与显示；④计划执行状态与风险表达；⑤方法评价。直接把五项当五个工作拆，硕士体量装不下且互不连贯。归并的依据是**问题的层次**：

- 内容②是一个**表示与算法问题**（骨面如何随磨钻运动变化）——独立成**工作一**，它是课题"预期成果"中"一种面向该场景的动态 surface 表示或更新方法"的直接来源，也是全课题的理论内核；
- 内容③是一个**性能与系统问题**（从工具运动到可视化反馈的实时性，CUDA/GPU 加速）——独立成**工作二**，它产出"一个能够读取骨表面、手术计划和工具轨迹的可视化原型"（预期成果原文），把工作一的方法变成跑得动的系统；
- 内容④+⑤同属**应用与验证问题**（显示什么状态信息、方法好不好）——合并成**工作三**，它把工作二的系统从"会动"升级为"有用"（风险表达），并用几何误差/效率/网格质量/稳定性/可视化效果的实验闭环证明（预期成果第 5、6 条）；
- 内容①（需求分析）**不设独立工作**：它是贯穿三者的背景论证材料，且文献调研阶段（02–12 号精读，特别是 10/12 号的需求清单）已完成大部分，作为论文绪论与需求分析章节。

课题文档原文中与之呼应的关键句：课题"拟以……三角表面模型为输入，研究手术磨钻作用下骨表面的动态表达和可视化问题"——三大工作恰好覆盖"动态表达（一）、计算（二）、可视化（三）"。

## 二、总体框架：一条数据流串起三个工作

```
输入：CT 重建三角网格骨面 + 手术计划（目标骨面/植入物 CAD）+ 磨钻轨迹（球形磨钻位姿序列）
         │
         ▼
【工作一：动态表面表示与增量更新】（算法层）
  磨钻扫掠区 → 表面更新算子（删除+填充）→ 质量维护 → 当前骨面
         │  当前骨面（网格）+ 剩余深度场
         ▼
【工作二：GPU 实时计算与可视化原型】（系统层）
  受影响区域筛选 → GPU 并行更新 → 渲染管线 → 三维显示（剩余量/工具位置）
         │  实时显示的系统 + 性能数据
         ▼
【工作三：状态与风险表达 + 评价实验】（应用与验证层）
  当前面 vs 计划面 → 完成度/过磨/边界/误差 → 与离线高精度真值对比 → 指标报告
```

连贯性体现在三处：**数据流连贯**（工作一的输出是工作二的输入，工作二的系统是工作三的实验对象）；**技术连贯**（工作一的更新算子决定工作二的 GPU 实现粒度，工作二的性能决定工作三评价的量级）；**论证连贯**（工作三的评价结果反过来支撑工作一方法的优劣结论，构成完整闭环）。

## 三、工作一（v1）：面向磨削的动态骨表面表示与增量更新方法

**对应课题文档**：研究内容②（动态骨表面表示与更新：根据磨钻位置、姿态和运动轨迹对局部骨表面连续更新，保持表面连续性、几何精度和网格质量）；候选方向二（动态表面的局部重建与质量保持）为主体，融合候选方向一的核心算子思想与候选方向四的自适应机制。

**核心研究问题**：磨钻连续运动下，如何对局部骨表面做增量更新，使长序列磨削后表面仍保持连续、精确、网格质量不退化。

**研究内容（四个递进小点）**：

1. **磨削更新的形式化**：把"骨面-磨钻扫掠"交互表达为空腔算子实例（05 号，Mahmoud）——磨钻扫掠区覆盖的三角形集为空腔（删除集），磨削后表面为填充集；因磨钻是球体，填充顶点可**重投影到解析球面/扫掠面**精确放置（06 号，Schmidt 展望一节的方案，绕开网格级求交误差）。此步产出更新算子的数学定义与正确性论证。
2. **网格质量保持机制**：更新后在受影响邻域运行约束重网格（分裂/折叠/翻转/平滑四遍 + 约束图，06 号）——磨削区内部自由重网格，**计划边界轮廓与解剖特征边锁定**（约束图不可变原则）；解决候选方向二点名的"重复磨削后的退化三角形、裂缝、法向不连续"问题。
3. **重复磨削与近重合处理**：同一区域多次磨削时，磨钻球面与已磨面**近重合**——引入容差化相交判定（06 号"加厚三角形"策略）+ 剩余深度场扣除机制（08 号 RV 更新的轻量化变体：以标量场而非几何体维护"已磨除"状态），避免误差累积与网格膨胀。
4. **精度预算与误差分析**：按 07 号（Nehring）的证明式方法为更新算子设计数值方案（坐标量化界限、迭代稳定性），对接 04 号文档确立的误差预算目标（表面几何误差 ≤0.1 mm 量级，显著小于系统级 0.5 mm）。

**可交付成果**：一种动态 surface 表示/更新方法（预期成果第 2 条）+ 算子级单元测试（简单磨削情形有解析真值，08 号的验证范式）。

**为什么排第一**：它是全课题的理论内核与后续两个工作的地基；且技术风险最集中，应最先攻克。

## 四、工作二（v1）：GPU 实时计算与可视化原型系统

**对应课题文档**：研究内容③（实时计算与显示：局部表面相交检测、受影响区域筛选、曲面更新、法向计算和显示的高效实现；明确点名"可将 CUDA、GPU 并行计算或计算着色器作为加速手段"）；候选方向一（增量更新与实时实现，GPU 加速关键计算环节）为主体；候选方向四（多分辨率自适应表达）作为其中的调节机制。

**核心研究问题**：从磨钻运动输入到可视化反馈的全管线如何在 GPU 上达到实时，并在几何精度、网格规模与实时性之间可调。

**研究内容（四个小点）**：

1. **原型系统架构**：实现"读取骨表面、手术计划和工具轨迹"的可视化原型（预期成果原文），模块化为：数据输入（CT 网格 + 计划 + 轨迹回放）、更新执行、渲染显示、指标采集四部分；以工作一的算子为更新内核。
2. **受影响区域筛选的 GPU 加速**：Morton 码排序 + LBVH/八叉树并行构建（09 号，Karras）做磨钻邻域三角形检索，支持"每次更新后毫秒级重建索引"；对照 08 号（Gong）的八叉树候选池流程给出 GPU 化改造。
3. **表面更新的 GPU 执行**：基于 RXMesh 动态网格框架（05 号，官方开源，reference/ 已就位）实现空腔删除与填充的 CUDA kernel；**针对性解决其自述软肋**——磨削负载"空间集中、时间连续"导致的并行度不足（05 号第七节），方案候选：表面更新（局部）与质量维护（较大邻域）分阶段并行、批量帧积压合并处理、围绕磨钻的动态 patch 焦点迁移。此点是课题方法层面最有把握立住的**创新候选**。
4. **多分辨率自适应与性能-精度调节**：磨削区按需加密（目标边长对应显示精度，粗磨 0.5 mm/精磨 0.1 mm 可调，06 号的 lmax 旋钮思想；Morton 码分层管理，09 号），平坦区与远离区稀疏；输出精度-规模-帧率的可调工作点。

**可交付成果**：可视化原型 + GPU 加速模块 + 性能分析（预期成果第 3、4 条：实时计算与显示方面的实现及性能分析）。

**量级依据**：显示 60 fps、更新延迟 <100 ms 已远超临床需要（磨削全程分钟级，10 号）；百万面级网格更新局部区域，Karras 索引重建毫秒级、RXMesh 空腔操作共享内存级——实时预算技术上从容。

## 五、工作三（v1）：计划执行状态与风险可视化及实验评价

**对应课题文档**：研究内容④（比较当前骨面和计划骨面，显示尚需去除区域、剩余磨削深度、计划完成程度、可能的过度磨削及工具与安全边界的关系）+ 研究内容⑤（从几何误差、计算效率、网格质量、连续运行稳定性和可视化效果评价，与离线高精度结果或已有 surface 处理方法比较）；候选方向三（计划误差和不确定性可视化）作为可视化表达的核心创新接口。

**核心研究问题**：在实时更新的表面之上，表达哪些状态与风险信息、如何表达，以及如何实验证明整套方法有效。

**研究内容（四个小点）**：

1. **状态信息模型与界面设计**：以 12 号文档的需求清单为规格——剩余磨削量（蓝色区域）、完成度（蓝色消失）、过磨警告（黄色）、工具-边界关系、安全边界可视化；基线对齐 Mako 产品行为（10 号），**增量做"产品未覆盖"项：配准/跟踪/延迟误差的传播显示与风险极值表达**（11 号：43% 转人工源于配准故障；04 号：尾部风险框架——显示最坏情况边界而非均值色阶）。
2. **可视化效果评估**（轻量人因，可选/加分项）：以 NASA-TLX + 李克特量表做小型用户实验（11 号方法），对比"有/无风险显示"的认知负荷与判断准确率；若条件不足则以专家访谈替代。
3. **几何精度评价**：以离线高精度方法（07 号 Nehring 路线 / cgal-nef）对同一磨削轨迹计算精确最终骨面作为真值，度量实时方法的几何误差；简单情形（平面/球窝磨削）用解析解（08 号范式）。
4. **综合性能与稳定性评价**：几何误差、计算效率（帧率/延迟/各模块耗时）、网格质量（长序列磨削后的三角形质量分布——工作一质量机制的验证）、连续运行稳定性（小时级连续磨削压力测试）；与基线方法对比（RXMesh 原生应用 / WMTK / 07 号 CPU 管线）。

**可交付成果**：面向肩胛盂磨削任务的精度、效率和稳定性评价（预期成果第 5、6 条）+ 状态可视化设计（支撑论文的应用贡献章节）。

## 七、创新点凝练建议与风险预案

**三个候选创新点**（按把握度排序，供开题时与导师确认取舍）：

1. **系统级**：面向"空间集中、时间连续"磨削负载的 GPU 实时表面更新管线——针对 05 号自述的通用动态网格框架软肋（局部集中操作并行度不足）给出针对性方案（工作二第 3 点），有明确的文献缺口与对照基线；
2. **方法级**："空腔删除 + 解析球面重投影填充 + 约束重网格"的磨削更新算子——网格拓扑近似与解析几何精确的混合（工作一第 1、2 点），兼顾精度（0.1 mm 预算）与质量保持（方向二）；
3. **应用级**：计划执行状态的误差-风险可视化（含误差传播与尾部风险表达）——产品现状未覆盖、且有 11 号文献的真实失效模式背书（工作三第 1 点）。

**风险预案**：

- **风险一（工作一迭代稳定性不达标）**：退守混合表示——磨削区局部改用高度场/剩余深度场（标量）+ 外围网格边界的混合方案，精度论证按 08 号思路重做；
- **风险二（工作二 GPU 并行度提升不显著）**：创新点 1 降级为"工程优化"，论文重心移向创新点 2+3（算法+应用），GPU 部分作为性能验证而非主贡献；
- **风险三（工作三用户实验条件不足）**：预设降级路线（专家访谈代替 NASA-TLX 实验，12 号清单代替实证验证），保证评价体系仍以几何/性能/稳定性等客观指标完整闭合。

**时间量级建议**：工作一约 1 学期（含方案调研收尾与算子实现）、工作二约 1 学期、工作三穿插进行、评价与论文撰写约 0.5 学期——与硕士两年半-三年节奏兼容（具体以开题计划为准）。
