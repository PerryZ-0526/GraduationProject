# Geogram几何基线审计

本目录单独评价TOG 2025 Geogram精确网格CSG，不与项目自研候选共同调参。实验使用固定提交`130442ff0f0c069d48ab4ebb4012218f3d861cf2`和17位有效数字OBJ适配器，不修改第三方源码。

## 研究问题

1. 球形工具的三角离散等级怎样影响几何误差、网格规模和耗时。
2. 共面简化是否是当前坏三角形的主要来源。
3. 相同材料集合改变工具顺序、重复次数或轨迹分段后，输出表面是否保持一致。
4. 逐步把差集结果回灌，与“先累计工具并集、再对初始骨面做一次差集”是否一致。

## 运行

首次运行或适配器源码变化后构建：

```bash
../共同运动记录与方法对照/build_geogram_baseline.sh
```

运行最小回归和正式审计：

```bash
../../.venv/bin/python -m unittest -v test_geogram_audit.py
../../.venv/bin/python experiment.py
```

结果写入`实验结果/<北京时间>/`，包括`results.json`、各分支开放上表面、完整闭合OBJ和Geogram日志。当前正式证据为`实验结果/20260922_142029/`，其中重复工具使用相同输入运行5次，不根据单次成功或失败选择结论。

## 结论边界

- 输入是解析倾斜平面和仿真球形工具运动，不是真实CT或实采轨迹。
- “精确CSG”针对给定三角网格输入，不消除球面和扫掠体的离散误差。
- 几何误差采用顶点、面心和密集目标网格的抽样距离，不是连续Hausdorff证书。
- PyMeshLab自交结果只记为检测器报警，未经独立精确复核时不解释为真实穿插。
- Geogram未包含质量维护；几何基线通过不等于最终网格交付通过。
