## 2. 什么样的结合值得研究？

我更看好一个明确的问题：

> **能否利用布尔运算提供的变化区域、曲面来源和交线信息，让网格维护减少无关计算，同时降低连续磨削中的几何漂移？**

目前的串联主要把Geogram输出当成一张网格交给PaMO。更深入的结合，可以让前者提供的信息直接决定后者如何工作。

### 方向一：由布尔变化驱动局部维护

Geogram端识别本次新增切削面、交线和受影响邻域，维护端据此确定更新范围，并在必要时扩域。

需要解决的实质问题包括：

- 局部区域与未修改骨面怎样保持一致连接；
- 局部操作怎样检查与远处表面的碰撞；
- 什么条件下必须扩大区域或退回全量处理。

**创新空间在这些规则及其依据。** 单纯“裁一块网格，再调用PaMO”还不够。

### 方向二：在维护过程中利用几何来源约束

区分原骨面、工具扫掠面和真实交线，让投影与简化遵守各自的几何约束。例如，交线附近的顶点不能任意投到相邻另一张面上。

但必须注意：**PaMO本来就有回到输入表面的安全投影和特征恢复。** 因此“增加投影”本身不新；我们需要证明，利用布尔来源信息，能够解决普通安全投影在连续切削中的具体问题。[PaMO原论文](https://arxiv.org/abs/2509.05595)

这也不同于此前失败的“来源标签限制翻边”：新的假设必须对应明确的漂移或错投现象，而非仅增加限制。

**建议先以方向一为主，方向二只在发现具体几何问题后加入。** 同时改很多机制，会很难解释收益来自哪里。以上都是候选，尚未经过充分查新和实验验证。

## 3. 用什么指标才能证明价值？

**指标应当检验贡献，不能因为现有结果不好就换一个容易赢的指标。** 我建议保留小角比例，再增加以下几组：

| 要证明的收益 | 关键指标 | 为什么有用 |
|---|---|---|
| 局部维护确实减少计算 | 完整延迟中位数/P95、实际处理面数占比、扩域与全量回退频率 | 判断局部化有没有净收益 |
| 未切区域保持稳定 | 独立定义的未受影响表面上，位移距离及法向变化 | 避免全网格平均误差掩盖无关区域漂移 |
| 连续更新没有明显积累误差 | 误差随磨削步数的曲线、重复路径后的额外形状变化 | 静态单帧通过无法回答这个问题 |
| 切削几何准确 | 相对独立参考的少切体积、多切体积、交线偏差 | 比单一平均表面距离更贴近磨削任务 |
| 网格质量得到维护 | `<10°/<5°/<1°`比例、绝对数量、面积占比；全网格和变化区域分别报告 | 防止大量未变化好面稀释局部问题 |
| 连续反馈更及时 | 已发布状态年龄、输入积压、有效发布覆盖率 | 反映用户实际看到的信息有多滞后 |

体积与距离指标都要交代参考几何的误差；抽样最大距离仍只能称为抽样结果。

**最有说服力的是“质量—误差—耗时”的权衡曲线：**

- 在相近几何误差和质量分布下，我们更快；
- 在相同计算预算下，我们几何更准确或小角面更少；
- 随序列增长，我们的漂移或积压增长更慢。

这比追求所有指标同时胜出，也比只宣布达到某个硬阈值，更符合当前研究目标。

## 4. 怎样证明“＞2”来自结合本身？

核心对照应至少包括：

1. **原版串联**：Geogram＋完整PaMO。
2. **公平工程基线**：同样享有预加载、传输和计时优化的串联。
3. **普通局部维护**：使用一般空间邻域确定维护范围。
4. **布尔信息驱动的候选**：使用变化与交线信息；分别关闭关键机制做消融。

所有组使用相同输入、硬件、几何检查和质量统计，并在冻结方法后评估独立路线。

**如果候选只胜过逐帧启动的原版，却胜不过同样优化过的串联，就主要是工程收益；如果它进一步胜过普通局部维护，且消融能定位到布尔信息的作用，才有较强证据支持“协同结合”的贡献。**

我的判断是：**目前已有一个可用于研究的组合基线；最值得争取的创新，是让布尔运算的信息真正指导后续维护，并用连续序列中的效率、漂移与质量权衡证明它。**
