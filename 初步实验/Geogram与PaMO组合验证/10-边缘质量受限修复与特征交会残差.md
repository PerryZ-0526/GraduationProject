## 一、固定输入与方法

输入是09号隔离 `4×FLT_EPSILON` 符号变体完整三阶段的 s3/s4 最终闭合网格；它们各为单分量、零自交报警，但分别有390/492个坏面。两例仍是同一解析倾斜交叉场景的配置变体，不当作独立骨标本。几何参照沿用0.025 mm离散解析网格，质量门槛沿用**每个三角面**最小角≥25°且`q≥0.4`。

先复用07号固定 PyMeshLab 等长重网格设置：10次、目标边长0.06 mm、特征角30°、曲面距离检查开启、最大偏离0.02 mm。此步对最终网格而非阶段一网格运行。为识别其残留的短边缺陷，后续只在质量失败邻域试受限短边折叠：边长≤0.02 mm、边两侧夹角≤30°、中点位移≤0.012 mm，须满足流形链接条件、局部坏面数严格下降和受影响面法向不翻转。接着复用09号近共面保特征翻边规则。两个位置调整探查分别限于近直线锐边二度顶点的切向（夹角≥150°，累计位移≤0.015或0.03 mm）和非锐边顶点的切平面八方向（累计位移≤0.02 mm）；尖角及锐边分叉保持固定。最后再运行同一翻边规则检查互补性。

脚本为`short_edge_collapse_probe.py`、`quality_flip_probe.py`、`feature_tangent_relax_probe.py`、`smooth_tangent_relax_probe.py`。这是一组**静态开发探查**，并未改写作者 PaMO，也未集成连续更新。参数按已观察到的约0.008–0.013 mm短边、约0.06 mm长边和已有几何预算选取，不能从两例效果推断通用最优配置。

## 二、逐阶段结果

| 静态输出 | s3面数 / 坏面 / 自交报警面 | s4面数 / 坏面 / 自交报警面 |
| --- | ---: | ---: |
| 09号符号变体完整三阶段 | 2134 / 390 / 0 | 3920 / 492 / 0 |
| 固定等长重网格 | 28872 / 39 / 8 | 29430 / 36 / 0 |
| 受限短边折叠 | 28858 / 26 / 0 | 29424 / 30 / 0 |
| 保特征翻边 | 28858 / 22 / 0 | 29424 / 29 / 0 |
| 锐边切向≤0.015 mm | 28858 / 9 / 0 | 29424 / 14 / 0 |
| 从翻边输出另起一支：锐边切向≤0.03 mm | 28858 / 7 / 0 | 29424 / 11 / 0 |
| 在0.03 mm支线上调整非锐边点 | **28858 / 5 / 0** | **29424 / 8 / 0** |
| 再次保特征翻边 | 5个坏面、接受0次 | 8个坏面、接受0次 |

短边折叠分别接受7/3次，将等长重网格后的坏面减少13/6个；完整审计还将s3的自交报警由8降至0。第一次保特征翻边分别接受5/2次，再减少4/1个。`0.015 mm`锐边切向调整接受13/15次，`0.03 mm`独立分支接受15/18次；后者再经非锐边调整各接受2/3次。调整只凭局部坏面数筛选，最终每一步仍通过原独立审计器检查分量、流形边、绕序、水密及自交报警。末两例均为单分量、水密、绕序一致、零自交报警。

最终 s3/s4 的最小角仍仅`5.719°/8.600°`，最小`q`为`0.1558/0.1910`，**没有达到质量门槛**。与同一离散解析参照的双向面积抽样最大值分别约`0.017543/0.016084 mm`，仍低于0.1 mm抽样门槛；这些数值不是连续 Hausdorff 上界。尤其s4的最小角从短边折叠后的`10.630°`降到切向调整后的`8.600°`，说明“坏面数严格下降”不能保证最差角单调改善；后续机制必须同时约束最差质量。

所有阶段的独立审计JSON、操作日志与`stage_summary.json`在`实验结果/20260927_边缘质量约束探查/`；14张阶段网格收入`边缘质量阶段网格.tar.gz`。`execution.json`列出固定参数、输入、脚本和证据文件的SHA256。网格原始明文仍留在本机同目录，版本库以压缩包保存。

## 三、剩余缺陷及机制判断

等长重网格的坏面中，s3有36/39、s4有36/36位于图域边缘0.1 mm带；典型三角形短边约0.008–0.013 mm而邻边约0.06 mm。受限折叠能够消去一部分狭窄边，也能消除s3这次等长重网格造成的自交报警；单靠翻边或固定目标边长无法清零。最终 s3 的5个残余坏面全部、s4的8个中有6个触及**特征度数至少3**的顶点，即多个检测到的锐边在同一点交会。其余2个s4坏面也位于边缘带。

本轮机制对分叉顶点和尖角刻意保持固定，故这些残差提示需要在特征交会处重新分配边与三角形，而不是继续扩大单点位移或一味增加全局面数。特征度数基于30°二面角检测，是当前网格上的计算分类；不能把每个分叉都认定为解析真实CSG交线。下一轮须将输入解析边界与网格锐边对应，区分应保留的真实交线和由重网格产生的伪特征，再做局部受约束重三角化。

## 四、证据边界与后续关口

本轮把s3/s4静态开发例的质量失败大幅缩小，并在最终候选保住已有抽样几何与当前拓扑检查；**两例均未通过全网格质量，不能发布或进入连续C0/C1磨削验收**。本轮未建立连续几何误差证书，未在冻结新案例、真实CT或更高分辨率上验证，也未测完整在线耗时。约29k面输出远大于PaMO原三阶段的约2k/4k面，不能据此宣称高效或实时。

下一候选应只改特征交会邻域：先固定真实CSG边与伪特征判据，再在局部面片上作最大最小角约束的重三角化；每次操作须维持水密、无自交和几何预算，并与09号仅符号修复及本轮质量操作做配对消融。静态全网格坏面清零后，才冻结独立新路线并考虑连续更新。
