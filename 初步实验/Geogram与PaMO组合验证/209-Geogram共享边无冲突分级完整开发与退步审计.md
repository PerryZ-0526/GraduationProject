# Geogram共享边无冲突分级完整开发与退步审计

生成时间：2026年10月06日 17:50:32（北京时间）

修改时间及修改内容：2026年10月06日 17:50:32（北京时间），首次记录两个版本各十一同源调用、首版执行失败、修复后的完整终态和二十二保存输出独立复审。

文档概述：同轮无冲突共享边分级大幅改善两个孔的细长面，但普通切口和薄壁有退步；保留旧版，不直接替换。全部为已见开发输入，尚无独立新参数或连续结果。

## 1. 单一生成改动

旧同步分级在一轮中可能同时拆分某个三角形的两条或三条边。新提案按边长度除以坏面短边目标的失衡值排序，每个原三角形一轮最多承担一条分裂边；共享边两侧仍用同一个中点。目标长度、区域重铺、七轮上限、自适应分支条件、最终质量采用规则、完整静态检查及局部连续表面证书保持。

两个分支使用同一选择函数，调用前冻结代码和十一共同输入；九参数已在207/208号用于验证及诊断，两CT也已见，本次全部为开发输入。旧版十一保存输出复用，两个新版本各实际调用十一输入，共二十二新调用，GPU调用零。没有改作者Geogram/PaMO安装。

## 2. 首版失败与撤回一致性修复

首版十合法返回、一薄壁执行失败。保护机制撤回某条边后，首版在剩余候选上重新排序，会选中同一已撤回父面上的其他竞争边，触发“撤回父面集合必须增大”的断言。失败日志及完整十一分母保留，不把它算作合法网格或CUDA失败。

修复版每轮先固定无冲突匹配集合，再排除已撤回边，同轮重试不重选替代竞争边。只修兼容性，没有放宽质量保护或几何门槛；冻结后重新执行全部十一输入。首版八项控制、修复版九项控制均保留，新增真实闭合四面体上的撤回重试控制。

## 4. 保存结构与独立表面界

修复版11/11保持共同输入拓扑和原固定扫描结构，孔/薄壁/窄缝每例三材料扫描。该结果不是全曲面最低厚度或孔径证书。所有十一新候选和十一旧基线重新加载并以当前固定EPECK检查器复核，二十二实际保存输出检查通过。

双向8192面积样本及全顶点分布重算一致；十一候选0.1毫米内面积样本最低比例100.000000%，面积样本最大距离2.86428933844e-14毫米。没有新增固定接受比例或峰值门槛。

独立公式重算实际采用分支的同步分裂覆盖、区域有向边界与高度残差，最大局部表面上界约5.83628268369e-14毫米；范围仅共同输入到本次局部维护，不涵盖前置CSG传播、CT提取或物理扫掠。实际私有生成89次无冲突分裂及1917项最终替换分量质量决定独立复算通过，包括撤回尝试，不仅审查最后最好输出。

## 5. 成本、保留范围与下一步

新候选客户端生成、保存、传输、审查中位6.017秒；两孔26.84/22.27秒，两CT34.07/85.44秒，非在线端到端时延。输出面数更大、工作量和选择轨迹不同，不宣称实时或全面加速。

本版可保留为替代生成提案，而不能无条件替换原版。下一入口应在相同当前输入上，按小角绝对数量及真实坏面面积统一比较旧批量与新无冲突候选；只采用不恶化的实际合法输出，不能按病例编号或已知结果选择。随后冻结新版本与新参数，并做真实父链连续评价。选中旧输出的事件必须明确记录复用/重新生成及成本，不能冒充新机制改进。

本批完成的是单机制开发与审查，没有新的未见评价、连续反馈或学术新颖性证明。原16刀连续父链及PaMO强对照保持原结论，整体研究继续。
