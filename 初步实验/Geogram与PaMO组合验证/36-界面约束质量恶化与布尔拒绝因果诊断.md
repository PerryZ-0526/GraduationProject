## 一、问题及实验

用户明确要求先验证因果链，成立才围绕自适应过渡带设计算法。35号已存在的接缝实现及静态结果是另一项开发证据，不能代替本任务的因果检验，也没有被改写。

冻结三个历史阻断前缀：交叉板体、长板体、长球体的第二刀；加浅磨、竖直、停钻三个已见成功对照。逐个读取同一次原始CSG、CGAL投影前快照及实际发布父网格，固定父与下一工具哈希。

第一批48次CSG：六例各原始父重复两次和同几何近共面质量翻边父一次，分别禁共面简化及默认简化，共36次；另新增同几何资产12次。发现重放不一致后，追加预先登记、固定种子交错的四例×两种父×八次禁简化，共64次。为拆开尺度混杂，另做六例×三条件×两轮CPU CGAL，共36次。全部返回码为0，部分输出未通过数值合法性门控；不能把这些情况写作Geogram进程崩溃。

## 二、等尺度干预

既有23个有效边界消融配对都降低小角比例，但实际目标边长也全部降低，不能把收益直接归因于边界自由度。新实验固定同一输入、两层活动域、CGAL三次迭代、同一旧二进制，比较以下条件：固定边界及原高尺度、解除活动边界及同高尺度、解除活动边界及原请求低尺度。来源交界与45度锐边仍保护。比较发生在CGAL质量生成阶段，没有混入最后GPU投影。

表中为低于10度的面数/全部面比例，两轮保存输出摘要一致，不把两轮当独立输入。

| 输入 | 固定边界、高尺度 | 解除边界、同高尺度 | 解除边界、低尺度 |
|---|---:|---:|---:|
| crossing_slab_01 | 176 / 8.9340% | 176 / 8.9340% | 139 / 5.9965% |
| long_slab_24 | 190 / 9.6840% | 190 / 9.6840% | 158 / 6.8935% |
| long_sphere_24 | 75 / 1.4040% | 75 / 1.4040% | 58 / 1.0435% |
| shallow_slab_01 | 188 / 9.5723% | 192 / 9.7760% | 142 / 6.1955% |
| vertical_sphere_01 | 61 / 1.1501% | 62 / 1.1689% | 47 / 0.8614% |
| stop_resume_sphere_01 | 67 / 1.2580% | 67 / 1.2580% | 45 / 0.8143% |

同高尺度时四例小角面数量不变、两例略增；解除策略不变而降低尺度时六例均减少。当前开发现象主要支持“长保护边通过0.76倍长度下限抬高实际目标尺度，影响生成质量”，不支持将收益直接解释为释放固定点。不能由此排除真实来源交界或锐边约束的其他作用。

## 三、同几何重复

近共面反事实翻边不移动父顶点，预算50次，面内平面容差1e-10毫米；重新加载后检查数值合法性及双向面积/全顶点探针不超过1e-7毫米。它作为三角化诊断，将整个父表面视为一类，不声称继承历史组织来源，也不是新发布算法。小角面数变化有限，交叉173→171、长板191→186、长球75→75。

追加64次的实际结果如下。每格八次使用同一父哈希、工具哈希、同一作者布尔二进制及相同清理。

| 输入 | 原父合法输出 | 共面质量干预父合法输出 |
|---|---:|---:|
| stop_resume_sphere_01 | 1/8 | 1/8 |
| crossing_slab_01 | 2/8 | 1/8 |
| long_sphere_24 | 0/8 | 0/8 |
| long_slab_24 | 6/8 | 8/8 |

交叉和停钻未显示稳定改善；长板仅呈有限样本改善；长球仍全部拒绝。第一批同一长板父曾一次合法、一次退化拒绝，追加原父六次合法两次拒绝；同输入实际输出哈希也不同。这是运行间三角化变动的直接见证，不能将单次反事实通过归因于小角改善。

## 五、更换假设

完整链条目前未获得支持，不继续以增加过渡带层数作为首选解释。后续优先假设改为：布尔输出的数值退化三角化及未排除报警，是一些输入拒绝的直接原因，需在几何保持和来源一致条件下单独处理。

本轮已经对六个第一批禁简化输出作只读检验：交叉同来源近共面翻边将退化面1→0，保持顶点和来源标签，双向探针约8.43e-16毫米，重新通过数值门控；长球31→30仍拒绝；停钻没有退化面但报警未排除，仍拒绝；其余三个原输出合法并保持合法。它支持部分局部三角化修复，不支持一般合法化已解决；不得改写历史发布/拒绝或宣称连续磨削完成。

长保护边与尺度质量应另作为一个受控问题，不能与输出合法化同时叠加后再声称收益来自过渡带。
